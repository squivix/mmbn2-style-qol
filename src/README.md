# Source

armips assembly for the patches in this repo. Building reproduces the released patches byte for byte.
`projects/bn2_styles/NOTES.md` has the research behind every address.

## Layout

| Folder | Patch | Code |
|---|---|---|
| `projects/bn2_battles` | `bn2_100battles` | `bn2_styles/battles.asm` |
| `projects/bn2_elemchoice` | `bn2_pickelement` | `bn2_styles/elemchoice.asm` |
| `projects/bn2_allstyles` | `bn2_keepstyles` | `bn2_styles/stylecap.asm` |
| `projects/bn2_progress` | `bn2_battlesleft` | `bn2_styles/progress.asm` |
| `projects/bn2_styles` | `bn2_styleqol` (all of them) | `main.asm` |

`bn2_styles/common.asm` holds the US / EU addresses. The two text menus are generated by `gen_text.py`
(`*.tpl` → `*.msg` with [TextPet](https://github.com/Prof9/TextPet)); the built `.msg` files are included, so
TextPet is only needed if you change the text. `savetool.py` makes a test copy of a save with a given battle count.

## Building (Windows)

You need:
- Python 3
- [armips](https://github.com/Kingcom/armips) v0.11 at `tools/armips/armips.exe`
- [Floating IPS](https://github.com/Alcaro/Flips) at `tools/flips/flips.exe`
- optional: TextPet at `tools/textpet/TextPet.exe` (with its `plugins` folder)
- your own clean ROMs at `roms/bn2_us.gba` and `roms/bn2_eu.gba` (see the main README for the checksums)

Then, from this folder:

```powershell
.\tools\build.ps1 bn2_styles           # build\bn2_styles_us.gba/.bps and build\bn2_styles_eu.gba/.bps
.\tools\build.ps1 bn2_elemchoice -Region us
```
